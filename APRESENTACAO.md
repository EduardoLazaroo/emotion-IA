# Apresentacao profissional

## Identidade e valor

Emotionfy e uma experiencia web que conecta faixa atual do Spotify, letras obtidas via Genius, analise emocional e geracao de imagem inspirada na musica. A aplicacao usa Flask no backend e HTML, CSS e JavaScript no frontend, integrando servicos externos por OAuth e APIs.

## Texto para publicacao

> O Emotionfy nasceu da ideia de transformar uma faixa em reproducao em uma experiencia multimodal. A aplicacao autentica o ouvinte no Spotify, recupera a musica atual, busca letras, interpreta elementos emocionais e produz uma imagem inspirada nessa leitura. O desafio tecnico foi orquestrar OAuth, dados musicais, letras e recursos de IA em uma interface unica. Por depender de credenciais e de um servico local complementar para analise e imagem, o projeto deve ser apresentado como prototipo de integracao, com configuracao explicita do ambiente.

## Evidencias visuais recomendadas

1. Entrada de autenticacao com Spotify.
2. Faixa atual e letra recuperada.
3. Resultado de analise emocional.
4. Imagem gerada e opcao de download.
